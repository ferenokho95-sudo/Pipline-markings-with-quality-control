# Проверки сборки

Дата: 28.10.2026. Среда: Linux amd64, Go 1.27.3. Минимальная версия по go.mod — Go 1.23.

Успешно выполнены:

- go test ./... — модульные и интеграционные тесты двух пакетов.
- go test -race ./... — тесты с детектором гонок.
- go vet ./... — статическая проверка.
- Полный CLI-цикл demo → import → metrics и prepare с предварительными метками.
- HTTP-клиент label/judge на httptest-сервере, включая отсутствие gold в запросе Judge.
- Сохранение завершённых строк после ошибки API и продолжение с --existing без повторной обработки готовых заданий.
- Независимая сверка двух значений Cohen’s κ из демо с sklearn.metrics.cohen_kappa_score. Python использовался только для независимой проверки, он не нужен для запуска проекта.
- Кросс-сборка Windows amd64: GOOS=windows GOARCH=amd64 go build -buildvcs=false. Готовый exe в архив не включён, исполнение на Windows не проверялось.

Набор содержит 15 тестовых функций, дополнительно есть параметризованные подтесты.
Демонстрационные числа: κ людей 0.6667; условное совпадение Judge 9/11 = 81.82%; покрытие Judge 11/12 = 91.67%.
Это результаты расчёта на заранее заданных синтетических ответах, не показатели реальных разметчиков или реальной LLM.

Реальные обращения к модели и пользовательскому Label Studio в рамках сборки не выполнялись. Интеграция с Label Studio проверена на фикстуре полного JSON-экспорта с числовым/объектным completed_by и отдельным ground_truth. Поддерживаемая схема и настройка описаны в README.md.
